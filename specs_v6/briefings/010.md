# Briefing 010 — provider-out-of-the-box

**Essência**: configurar o provider vira o fluxo que o operador conhece de
outras aplicações: colar a chave → a lista de modelos carrega **da API do
vendor** → escolher → verificar → pronto. Mockup M1 (`#m1`) + passo 5 do
wizard (M5, `#m5`). Hoje: lista hardcoded 2 gerações atrás, probe que não
força tool-call, console traduzindo degraded como Failing, e o texto falso
"This endpoint could not be asked what else it serves".

## O que a spec precisa cobrir

1. **Lista dinâmica de modelos** (`google_gemini` primeiro, desenho genérico
   por provider): endpoint de listagem chamado com a credencial armazenada
   (via credential proxy, nunca no browser), curadoria para modelos de texto
   generativos (excluir image/tts/robotics/lyria; incluir os `-latest`),
   cache com TTL curto + refresh manual ("Reload models"), fallback declarado
   quando a API de listagem falhar (aí sim a lista estática, rotulada como
   tal). O registry estático (`core/llm/onboarding/gemini.py:28-33`,
   `core/llm/registry.py`) vira fallback/enriquecimento (pricing, janela),
   nunca a fonte da lista.
2. **Probe honesto**: `_tool_call_check` (`core/llm/preflight.py:168`) força a
   chamada — Gemini `functionCallingConfig.mode: "ANY"` no request do probe
   (`core/llm/providers/gemini.py:193`), equivalente (`tool_choice`) nos
   demais providers em `core/llm/providers/`. Com a chamada forçada, resposta
   sem tool call vira **FAILED** (não degraded) — o modelo realmente não
   serve. `supports_tools=false` no descriptor continua degraded.
3. **Estado espelhado, fim da tradução**: console renderiza os três estados do
   preflight por check (passed/degraded/failed) com o vocabulário único
   (COMUM §6). Degraded explica consequência e saída, e **não bloqueia**;
   failed bloqueia. Vale para a tela Models & providers e para o passo 5 do
   wizard. O texto "the list has to come from its own documentation" morre.
4. **Tela M1**: card de estado no topo (chip + ação "Check again"), erro com
   hierarquia (chip → consequência → saída com verbo), "Set at" sem
   duplicação, "Return to inheriting the default" ao lado, papéis avançados
   colapsados em uma linha. Modelo com display name da API.
5. **Wizard passo 5 (M5)**: linha por dependência com chip + latência
   ("answered in 240 ms"), display names ("Prometheus", não "prometheus"),
   "N checks degraded, none failing" no rodapé, Continue liberado com
   degraded e segurado com failed. (A contagem única de passos é da 020 —
   não duplicar; citar a fronteira.)
6. **Segurança**: chave nunca volta ao cliente; listagem roda no gateway com a
   credencial do vault; logs não carregam a chave.

## Testes

- Unit backend: curadoria da lista (fixture com os 37 nomes reais colhidos em
  2026-08-16), probe com mode ANY (request capturado), mapeamento
  degraded/failed.
- Acceptance (`console/tests/e2e/010-provider-out-of-the-box.acceptance.spec.ts`):
  M1 e passo 5 — chips com as palavras exatas, lista de modelos vinda do mock
  da listagem (mock plane ganha o endpoint), erro estruturado, ausência das
  strings banidas (`google_gemini`, "Set at Set at").
