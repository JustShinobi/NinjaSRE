F01
Every screen
The measure cap is declared and no screen applies it
--width-page: 1360px is served on :root. On /agent at a 2498px viewport, <main> measures 2247px — 887px past the cap the system wrote for itself.
Four findings below are downstream of it: F06, a name broken mid-word in a narrow column with 900px spare beside it; F11, prose set at 950px per line; F12, columns that drift because nothing bounds them; F17, dead columns nobody notices because there is width to waste. Cap the page and all four get smaller before anyone touches them.
