# Locales

| Locale | Language | Maintainer | Pages |
|---|---|---|---|
| `en` | English | the project | all — this is the normative source |

No community translation exists yet. `README.md` in this directory is what one
would follow; the table above is where it would be recorded.

A locale is listed here once somebody has agreed to keep it current. An
unmaintained translation goes stale silently and tells readers things that used
to be true, so the maintainer column is not decoration — a row with nobody in it
is a row that should be removed along with its directory.
